## Overview
This project uses three gradient boosting frameworks: **LightGBM, XGBoost, and CatBoost**. These models are all built around decision trees and use gradient boosting to progressively improve prediction performance. While they share the same general boosting approach, each framework has its own method of building, growing, and optimizing trees. Using these three models provides different approaches to the same classification problem and allows their prediction performance to be compared and combined.

## The framework for these models is gradient boosting 
A framework provides the libraries and structure for building and training models, with different frameworks using different techniques to improve how the model learns and makes predictions. My code uses toolkits lightgbm, xgboost and catboost.

A tree is a prediction. To get the best prediction, we make more and more predictions sequentially with each tree having better outcome, until the last tree have the best outcome. It plants trees sequentially, each correcting the errors of the previous one.Making it better. The cycle is like **Create a Tree → Prediction → Error → create next Tree → Reduced the Error and make the predictions better → Repeat**. The last tree is always the best. Repeats the cycle until the last tree when there is no more error. 

## Tree structure
- **Roots** = the data foundation before any predictions (the beginning of the processs)
- **Stem** = It starts to connect data to decision branches.
- **Branches** = Each branch is a decision which acts as a conditional check before the outcome.
- **Leaves** = give the final outcomes

## toolkits summary
**Lightgbm** taught me about leaf-wise growth, where the model focuses on expanding the leaf that can reduce the most error. This allows it to learn quickly, but it also needs to be controlled to avoid overfitting. it acts as the **leaves** 
**XGBoost** showed me how trees can be built in a more controlled way, while using regularization to prevent the model from becoming too complex. This helps the model balance strong predictions with reducing overfitting. it acts as the **branches**
**CatBoost** helped me understand how a model can handle categorical features more effectively. It uses special methods when processing and learning from categorical data, which can help reduce bias and overfitting. It acts as the **roots**
These are the process of how the toolkits work in my tree to give me the data prediction at the end.

## Gradient slope 
In machine learning, I found out that the “gradient” in gradient boosting helps guide the model towards reducing its prediction error. XGBoost, LightGBM, and CatBoost repeatedly add new decision trees that use this error information to improve the predictions made by the previous trees.

## My Loss Curve (combine my three models together)
The loss curve shows a healthy downward trend, with the error decreasing quickly at the beginning and then slowing as the model gets closer to its best performance. I see this as the model moving downhill towards a lower error, where larger improvements happen early and smaller adjustments are made later. Lightgbm, xgboost, and catboost each follow this general gradient boosting idea, but they take different approaches to building and improving their decision trees along the way.

## The Cycle of Prediction of one tree
Gradient boosting builds trees one after another, with each new tree helping to correct previous prediction errors.

Gradient boosting starts with a tree that makes an initial prediction and calculates how much error it made. The gradient then shows the direction the model should move to reduce that error. A new tree is added to correct the previous mistakes, and this process continues tree by tree until the prediction error becomes smaller.
